# التوثيق

| المجلد | المحتوى |
|---|---|
| [`docs/deploy.md`](deploy.md) | النشر التلقائي على cPanel، والإعداد لمرة واحدة، والتراجع |
| `docs/specs/` | مواصفات كل قسم قبل بنائه: الهدف، والـ endpoints، والقرارات المفتوحة. ملف لكل قسم، مثل `19-wallet.md` و`20-gifts.md` |
| `docs/decisions/` | قرارات معمارية قصيرة: ماذا قررنا، ولماذا، وما البدائل. ملف لكل قرار، مثل `0001-monorepo.md` |
| `backend/docs/` | توثيق تشغيل ميزات الباك (cron، إعدادات، نشر) |
| `apps/web/docs/` | توثيق ميزات موقع العملاء |
